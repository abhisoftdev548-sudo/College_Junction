# Java Programming Course — Syllabus

Complete Java course following the same learning sequence as the C++ course.
**16 modules · 80 topics** — each module tagged with purpose, objectives, prerequisites, and difficulty.

Learning sequence: Basics → Fundamentals → Control Flow → Methods → Arrays/Strings → OOP → Advanced OOP → Exceptions/I-O → Collections → Generics/Lambdas → Streams/Modern Java → Concurrency → Memory/Performance → Problem Solving → DSA → Interview Prep.

---

## Module 1 — Java Basics
**Purpose:** Understand what Java is, how it runs everywhere, and write your first program.
**Objectives:** Explain JVM/bytecode; set up JDK; compile and run a program; use variables and I/O.
**Prerequisites:** None.
**Difficulty:** Beginner
**Topics:**
- 1.1 What is Programming and Java
- 1.2 Setting Up Java (JDK, JVM, JRE)
- 1.3 Your First Program and Program Structure
- 1.4 Variables and Data Types
- 1.5 Input and Output

## Module 2 — Fundamentals: Variables, Data Types, Operators
**Purpose:** Master the building blocks of every Java expression.
**Objectives:** Use primitive types, operators, type casting, and the Math class correctly.
**Prerequisites:** Module 1.
**Difficulty:** Beginner
**Topics:**
- 2.1 Variables and Constants (`final`)
- 2.2 Primitive Data Types
- 2.3 Operators and Expressions
- 2.4 Type Casting and Conversion
- 2.5 Math Class and Wrapper Types

## Module 3 — Control Flow
**Purpose:** Make decisions and repeat work.
**Objectives:** Use if/switch, all loop forms, break/continue, and nested loops; print patterns.
**Prerequisites:** Module 2.
**Difficulty:** Beginner
**Topics:**
- 3.1 Conditional Statements (if-else, switch)
- 3.2 Loops (for, while, do-while)
- 3.3 Loop Control (break, continue, labels)
- 3.4 Nested Loops
- 3.5 Pattern Programming

## Module 4 — Methods (Functions)
**Purpose:** Organize code into reusable, named units.
**Objectives:** Write methods with parameters/returns, overload them, and use recursion.
**Prerequisites:** Module 3.
**Difficulty:** Beginner
**Topics:**
- 4.1 Introduction to Methods
- 4.2 Parameters and Return Values
- 4.3 Method Overloading
- 4.4 Scope and Lifetime
- 4.5 Introduction to Recursion

## Module 5 — Arrays and Strings
**Purpose:** Work with collections of values and text.
**Objectives:** Use 1D/2D arrays, String, StringBuilder, and pass them to methods.
**Prerequisites:** Module 4.
**Difficulty:** Beginner
**Topics:**
- 5.1 Arrays (1D)
- 5.2 Multidimensional Arrays
- 5.3 The String Class
- 5.4 StringBuilder and StringBuffer
- 5.5 Arrays and Strings in Methods

## Module 6 — Object-Oriented Programming (Fundamentals)
**Purpose:** Model real-world entities with classes.
**Objectives:** Define classes/objects, constructors, encapsulation, static members, packages.
**Prerequisites:** Module 5.
**Difficulty:** Intermediate
**Topics:**
- 6.1 Classes and Objects
- 6.2 Constructors
- 6.3 Encapsulation and Access Modifiers
- 6.4 `this` and `static` Members
- 6.5 Packages and Imports

## Module 7 — Advanced Object-Oriented Programming
**Purpose:** Reuse and extend behaviour through the OOP pillars.
**Objectives:** Use inheritance, polymorphism, abstract classes, interfaces, enums, and records.
**Prerequisites:** Module 6.
**Difficulty:** Intermediate
**Topics:**
- 7.1 Inheritance
- 7.2 Polymorphism and Method Overriding
- 7.3 Abstract Classes and Interfaces
- 7.4 Enums
- 7.5 Records and Modern Java

## Module 8 — Exception Handling and File I/O
**Purpose:** Handle errors gracefully and persist data.
**Objectives:** Use try/catch/finally, custom exceptions, and read/write files safely.
**Prerequisites:** Module 7.
**Difficulty:** Intermediate
**Topics:**
- 8.1 Exception Basics (try-catch-finally)
- 8.2 Checked vs Unchecked and Custom Exceptions
- 8.3 File I/O Basics
- 8.4 Reading and Writing Files
- 8.5 Try-with-Resources and NIO

## Module 9 — Collections Framework
**Purpose:** Store and manipulate groups of objects.
**Objectives:** Use List, Set, Map, iterators, and sorting utilities.
**Prerequisites:** Module 8.
**Difficulty:** Intermediate
**Topics:**
- 9.1 Lists and ArrayList
- 9.2 Sets (HashSet, TreeSet)
- 9.3 Maps (HashMap, TreeMap)
- 9.4 Iteration (for-each, Iterator, ListIterator)
- 9.5 Sorting and the Collections Utility

## Module 10 — Generics and Lambdas
**Purpose:** Write type-safe, reusable, concise code.
**Objectives:** Use generics, wildcards, comparators, lambdas, and functional interfaces.
**Prerequisites:** Module 9.
**Difficulty:** Advanced
**Topics:**
- 10.1 Generics
- 10.2 Bounded Types and Wildcards
- 10.3 Comparable and Comparator
- 10.4 Lambda Expressions and Method References
- 10.5 Functional Interfaces

## Module 11 — Streams and Modern Java
**Purpose:** Process data declaratively with modern APIs.
**Objectives:** Use the Stream API, Collectors, Optional, and the Date/Time API.
**Prerequisites:** Module 10.
**Difficulty:** Advanced
**Topics:**
- 11.1 Stream API Basics
- 11.2 Intermediate Operations
- 11.3 Terminal Operations and Collectors
- 11.4 Optional
- 11.5 Date/Time API and Modern Features

## Module 12 — Multithreading and Concurrency
**Purpose:** Run work in parallel safely.
**Objectives:** Create threads, synchronize, use executors and concurrent collections.
**Prerequisites:** Module 11.
**Difficulty:** Advanced
**Topics:**
- 12.1 Threads and Runnable
- 12.2 Thread Lifecycle and Synchronization
- 12.3 Executors and Thread Pools
- 12.4 Concurrent Collections
- 12.5 CompletableFuture and Async Basics

## Module 13 — Memory and Performance
**Purpose:** Understand how the JVM manages memory.
**Objectives:** Explain heap/stack, GC, references, the string pool, and performance habits.
**Prerequisites:** Module 12.
**Difficulty:** Advanced
**Topics:**
- 13.1 JVM Memory Model (Heap and Stack)
- 13.2 Garbage Collection
- 13.3 Object References and Lifecycle
- 13.4 String Pool and Immutability
- 13.5 Performance Best Practices

## Module 14 — Problem Solving
**Purpose:** Build the method and mindset for solving problems.
**Objectives:** Apply approaches, patterns, Big-O, debugging/testing, and contest tips.
**Prerequisites:** Modules 1–13.
**Difficulty:** Advanced
**Topics:**
- 14.1 Problem-Solving Approaches
- 14.2 Common Patterns
- 14.3 Complexity Analysis (Big-O)
- 14.4 Debugging and Testing (JUnit)
- 14.5 Competitive Programming Tips

## Module 15 — DSA in Java (1)
**Purpose:** Implement classic data structures and algorithms in Java.
**Objectives:** Master arrays/strings DSA, linked lists, stacks/queues, recursion, and sorting/searching.
**Prerequisites:** Module 14.
**Difficulty:** Advanced
**Topics:**
- 15.1 Arrays and Strings in DSA
- 15.2 Linked Lists
- 15.3 Stacks and Queues
- 15.4 Recursion and Backtracking
- 15.5 Sorting and Searching

## Module 16 — DSA in Java (2) and Interview Prep
**Purpose:** Complete DSA and get interview-ready.
**Objectives:** Trees/BST, heaps, hashing, graphs, plus the interview loop and wrap-up.
**Prerequisites:** Module 15.
**Difficulty:** Advanced
**Topics:**
- 16.1 Trees and Binary Search Trees
- 16.2 Heaps and Priority Queues
- 16.3 Hashing and HashMap Internals
- 16.4 Graphs and Traversal
- 16.5 Interview Prep and Course Wrap-Up
