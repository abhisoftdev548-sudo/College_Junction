# C++ Programming Course — Syllabus

Complete C++ course covering the full learning sequence.
**16 modules · 80 topics** — each module tagged with purpose, objectives, prerequisites, and difficulty.

Learning sequence: Basics → Fundamentals → Control Flow → Functions → Arrays/Strings → Memory/Pointers → OOP → Advanced C++ → Modern C++ → STL → Problem Solving → DSA Prep → Trees → Graphs → Hashing/Advanced → Interview Prep & Project.

---

## Module 1 — C++ Basics
**Purpose:** Understand what programming and C++ are, and get a working environment.
**Objectives:** Explain how C++ runs; set up a compiler; write and compile a first program.
**Prerequisites:** None.
**Difficulty:** Beginner
**Topics:**
- 1.1 What is Programming
- 1.2 Introduction to C++
- 1.3 Setting Up C++ Environment
- 1.4 C++ Program Structure
- 1.5 Compilation and Execution

## Module 2 — C++ Fundamentals: Variables, Data Types, Operators
**Purpose:** Master the building blocks of every C++ expression.
**Objectives:** Use variables/constants, fundamental types, I/O, operators, and casting correctly.
**Prerequisites:** Module 1.
**Difficulty:** Beginner
**Topics:**
- 2.1 Variables and Constants
- 2.2 Data Types
- 2.3 Input and Output
- 2.4 Operators
- 2.5 Type Conversion and Casting

## Module 3 — Control Flow
**Purpose:** Make decisions and repeat work.
**Objectives:** Use if/switch, all loop forms, break/continue, and nested loops; print patterns.
**Prerequisites:** Module 2.
**Difficulty:** Beginner
**Topics:**
- 3.1 Conditional Statements
- 3.2 Loops
- 3.3 Loop Control Statements
- 3.4 Nested Loops
- 3.5 Pattern Programming

## Module 4 — Functions
**Purpose:** Organize code into reusable, named units.
**Objectives:** Write functions with parameters/returns, overload them, and use recursion.
**Prerequisites:** Module 3.
**Difficulty:** Beginner
**Topics:**
- 4.1 Introduction to Functions
- 4.2 Function Parameters and Return Values
- 4.3 Function Overloading
- 4.4 Scope and Lifetime
- 4.5 Introduction to Recursion

## Module 5 — Arrays and Strings
**Purpose:** Work with collections of values and text.
**Objectives:** Use 1D/2D arrays, C-strings and std::string, and pass them to functions.
**Prerequisites:** Module 4.
**Difficulty:** Beginner
**Topics:**
- 5.1 Arrays (1D)
- 5.2 Multidimensional Arrays
- 5.3 Strings
- 5.4 String Operations
- 5.5 Arrays and Strings as Function Parameters

## Module 6 — Memory and Pointers
**Purpose:** Understand how C++ lays out and addresses memory.
**Objectives:** Use pointers, pointer arithmetic, references, dynamic allocation, and smart pointers.
**Prerequisites:** Module 5.
**Difficulty:** Intermediate
**Topics:**
- 6.1 Pointers Basics
- 6.2 Pointer Arithmetic
- 6.3 References
- 6.4 Dynamic Memory Allocation
- 6.5 Smart Pointers

## Module 7 — OOP (Object-Oriented Programming)
**Purpose:** Model real-world entities with classes.
**Objectives:** Build classes, constructors/destructors, encapsulation, inheritance, and polymorphism.
**Prerequisites:** Module 6.
**Difficulty:** Intermediate
**Topics:**
- 7.1 Classes and Objects
- 7.2 Constructors and Destructors
- 7.3 Encapsulation and Access Specifiers
- 7.4 Inheritance
- 7.5 Polymorphism

## Module 8 — Advanced C++
**Purpose:** Go deeper into the language's power features.
**Objectives:** Write templates, handle exceptions, overload operators, and do file I/O.
**Prerequisites:** Module 7.
**Difficulty:** Intermediate
**Topics:**
- 8.1 Templates
- 8.2 Exception Handling
- 8.3 Operator Overloading
- 8.4 Namespaces
- 8.5 File I/O

## Module 9 — Modern C++
**Purpose:** Write idiomatic C++11/14/17/20 code.
**Objectives:** Use auto, lambdas, move semantics, structured bindings, and constexpr.
**Prerequisites:** Module 8.
**Difficulty:** Intermediate
**Topics:**
- 9.1 Auto and Type Deduction
- 9.2 Lambda Expressions
- 9.3 Move Semantics
- 9.4 Range-based For and Structured Bindings
- 9.5 constexpr and Compile-Time Programming

## Module 10 — STL (Standard Template Library)
**Purpose:** Use C++'s ready-made containers and algorithms.
**Objectives:** Master vectors, maps/sets, iterators, algorithms, and practical STL usage.
**Prerequisites:** Module 9.
**Difficulty:** Intermediate
**Topics:**
- 10.1 Vectors and Sequence Containers
- 10.2 Associative Containers (Map and Set)
- 10.3 Iterators and Ranges
- 10.4 STL Algorithms
- 10.5 STL in Practice

## Module 11 — Problem Solving
**Purpose:** Build the method and mindset for solving problems.
**Objectives:** Apply approaches, patterns, Big-O, debugging/testing, and contest tips.
**Prerequisites:** Modules 1–10.
**Difficulty:** Advanced
**Topics:**
- 11.1 Problem-Solving Approaches
- 11.2 Common Patterns
- 11.3 Complexity Analysis (Big-O)
- 11.4 Debugging and Testing
- 11.5 Competitive Programming Tips

## Module 12 — DSA Prep
**Purpose:** Implement classic data structures and algorithms.
**Objectives:** Master arrays/strings DSA, linked lists, stacks/queues, recursion, and sorting/searching.
**Prerequisites:** Module 11.
**Difficulty:** Advanced
**Topics:**
- 12.1 Arrays and Strings in DSA
- 12.2 Linked Lists
- 12.3 Stacks and Queues
- 12.4 Recursion and Backtracking
- 12.5 Sorting and Searching

## Module 13 — Trees
**Purpose:** Master hierarchical data structures.
**Objectives:** Implement binary trees, BSTs, traversals, heaps, and tries.
**Prerequisites:** Module 12.
**Difficulty:** Advanced
**Topics:**
- 13.1 Binary Trees
- 13.2 Binary Search Trees (BST)
- 13.3 Tree Traversals
- 13.4 Heaps and Priority Queues
- 13.5 Tries (Prefix Trees)

## Module 14 — Graphs
**Purpose:** Model networks and relationships.
**Objectives:** Represent graphs; traverse with BFS/DFS; find shortest paths and MSTs.
**Prerequisites:** Module 13.
**Difficulty:** Advanced
**Topics:**
- 14.1 Graph Representation
- 14.2 Graph Traversal (BFS and DFS)
- 14.3 Shortest Paths
- 14.4 Minimum Spanning Tree
- 14.5 Disjoint Set Union (Union-Find)

## Module 15 — Hashing and Advanced Topics
**Purpose:** Master hashing and advanced algorithm techniques.
**Objectives:** Use hashing, greedy, DP, two pointers/sliding windows, and bit manipulation.
**Prerequisites:** Module 14.
**Difficulty:** Advanced
**Topics:**
- 15.1 Hash Functions and Collisions
- 15.2 Greedy Algorithms
- 15.3 Dynamic Programming
- 15.4 Two Pointers and Sliding Windows
- 15.5 Bit Manipulation

## Module 16 — Interview Prep and Project
**Purpose:** Get interview-ready and consolidate everything.
**Objectives:** Solve interview problems, write clean code, build a mini project, and wrap up.
**Prerequisites:** Module 15.
**Difficulty:** Advanced
**Topics:**
- 16.1 Interview Preparation and Problem Walkthroughs
- 16.2 Clean Code and Code Style
- 16.3 Building a Complete Mini Project
- 16.4 Common C++ Pitfalls and Gotchas
- 16.5 Course Wrap-Up and Next Steps
